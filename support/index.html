よくあるご質問

物語が生成されません
iOS 26 以降の対応端末でのみ物語生成をご利用いただけます。Free プランは Apple Foundation Models（オンデバイス）を使用するため、対応外の端末では生成できません。
HealthKit の数値が反映されません
「設定 → プライバシーとセキュリティ → ヘルスケア → Katarive」で読み取り権限が有効になっているかご確認ください。位置情報・カレンダー・写真も同様に「設定 → Katarive」から権限を確認できます。
Premium プランについて
Premium は買い切りです。自動で更新される課金はありません。
購入の復元
アプリ内の「設定」→「プラン」→「購入を復元する」からご利用ください。同じ Apple ID で購入された Premium プランが復元されます。
データの削除
アプリを削除すると、端末内のデータは削除されます。Premium で iCloud に保存したデータは残るため、iPhone の「設定」→ ご自身の名前 →「iCloud」→ ストレージの管理から Katarive のデータを削除してください。アプリ内で削除する機能は、今後のバージョンで対応予定です。詳しくはプライバシーポリシーをご覧ください。
物語の品質について
Free プランはオンデバイス LLM、Premium プランはクラウド LLM を使用しており、Premium のほうがより自然で文学的な仕上がりになります。詳しくはプライバシーポリシーをご覧ください。
