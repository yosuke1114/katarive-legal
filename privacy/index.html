Katarive プライバシーポリシー

最終更新日：2026年4月29日

1. はじめに

Katarive（以下「本アプリ」）は、お客様のプライバシーを尊重し、個人情報の保護に努めています。本ポリシーは、本アプリが収集する情報の種類、使用方法、および保護方法について説明します。

2. 収集する情報

2-1. デバイス上でのみ処理する情報（外部送信なし）

本アプリは以下のデータを端末内のみで処理し、外部サーバーへ送信しません。

データ種別用途取得方法
歩数・消費カロリー・移動距離物語生成のヒントHealthKit（任意）
睡眠時間物語生成のヒントHealthKit（任意）
心拍数（平均）物語生成のヒントHealthKit（任意）
訪問地（概略）物語生成のヒントCore Location（任意）
カレンダー予定物語生成のヒントEventKit（任意）
写真のメタデータ（種類のみ）物語生成のヒントPhotos（任意）

2-2. Apple のサービスを通じて処理する情報

  • StoreKit 2：課金トランザクションは Apple のサーバーで処理されます。本アプリはレシートを受け取るのみで保存しません。
  • iCloud（将来対応予定）：日記データのバックアップ・同期に使用する予定です。

2-3. Premium ユーザーのみ外部送信される情報

Premium プランをご利用の場合、より高品質な物語生成のため以下の情報が外部サーバーへ送信されます。Free プランの場合は送信されません。

データ種別送信先用途
物語の事実下書き（歩数・睡眠時間・天気など端末側で生成した日本語テキスト） 開発者運用の Firebase Functions（asia-northeast1） → Anthropic Claude API 物語の流暢化
StoreKit 2 のトランザクション JWS 同上 Premium 認証
  • 送信される事実下書きには、氏名・住所・正確な座標・写真本体・カレンダー本文は含まれません。
  • HealthKit の生データ（心拍数の時系列など）も送信されません。
  • 開発者および Anthropic は本アプリ用途以外でこのデータを利用しません。
  • Anthropic のプライバシーポリシーは https://www.anthropic.com/legal/privacy を参照してください。

3. 情報の使用目的

収集した情報は、以下の目的にのみ使用します。

  • 本アプリの物語生成機能の提供
  • ウィジェットへのデータ共有（App Group 経由、端末内のみ）
  • アプリ機能の改善

4. 情報の第三者提供

本アプリは、お客様の個人情報を第三者に販売・共有・開示しません。

5. 物語生成 AI について

5-1. Free プラン

iOS 26 以降では、Apple の Foundation Models（オンデバイス LLM） を使用して物語を生成します。このモデルは端末上で完全に動作し、テキストデータが外部に送信されることはありません。

5-2. Premium プラン

Premium プランでは、より自然で文学的な物語を生成するため Anthropic Claude（クラウド LLM） を使用します。物語の事実下書き（端末で生成した日本語テキスト、200文字程度）が、開発者運用の Firebase Functions を経由して Anthropic に送信され、推敲済みのテキストが返ってきます。送信内容の詳細は「2-3」を参照してください。

iOS 25 以前では、物語生成機能はご利用いただけません。

6. データの保存と削除

  • すべてのデータは端末のローカルストレージ（SwiftData）に保存されます
  • アプリを削除することで、すべてのデータが削除されます
  • 設定 → Katarive → 「すべてのデータを削除」からも削除できます（将来実装予定）

7. 子どものプライバシー

本アプリは13歳未満のお子様を対象としていません。

8. プライバシーポリシーの変更

本ポリシーを変更する場合、アプリのアップデートを通じてお知らせします。
